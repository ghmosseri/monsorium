# Fonts

All fonts here are watermark-free woff2 subsets (Latin, Latin-1, Latin Ext-A,
punctuation), built by `tools/build-assets.py`. Display faces are chosen to
echo psychedelic Art Nouveau and punk baroque; all are free for personal use.

| File | Source / licence | Used for |
|---|---|---|
| federant | Google Fonts, OFL — Art Nouveau | brand, "When", "the", "has" |
| new-rocker | Google Fonts, OFL — punk-baroque blackletter | "Mouth", "No", section titles, drop cap |
| cinzel-decorative-bold | Google Fonts, OFL — baroque swash capitals | "Witnesses", plates, citation |
| kings | Google Fonts, OFL — punk calligraphy | bottle titles |
| gideon-roman | Google Fonts, OFL — classical | captions, contact addresses |
| hempa-sans-*, cheyenne-sans-var* | psychesubfont (Cheyenne Sans is OFL) | subtitle, ribbon |
| brokuets-sans | psychebodyfont/Brokuets Sans Demo (free for personal use; no watermark) | body text |
| optician-sans | psychebodyfont/Optician Sans | labels, meta |

Not shipped: Biological Crossroads, Certain Reasons and Maritime Network demos
(177Studio) and Stinger Wide Trial replace letters, digits or punctuation with
"TRIAL FONT" stamps. Slowji, Shrikhand and Bagel Fat One were retired for
reading too bubbly.
