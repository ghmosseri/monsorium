# Fonts

All fonts here are watermark-free woff2 subsets (Latin, Latin-1, Latin Ext-A,
punctuation), built by `tools/build-assets.py`.

| File | Source | Used for |
|---|---|---|
| slowji, slowji-3d | psychetitlefont/Slowji (personal & commercial use) | title, brand |
| gideon-roman | Google Fonts, OFL — stands in for Biological Crossroads Demo | title ("the"), plate captions |
| shrikhand | Google Fonts, OFL — stands in for Maritime Network Demo | title ("has"), accents |
| bagel-fat-one | Google Fonts, OFL — stands in for Certain Reasons Demo | title ("Mouth"), section titles |
| hempa-sans-*, cheyenne-sans-var* | psychesubfont (Cheyenne Sans is OFL) | subtitle, ribbon |
| brokuets-sans | psychebodyfont/Brokuets Sans Demo (free for personal use; no watermark) | body text |
| optician-sans | psychebodyfont/Optician Sans | labels, meta |

Not shipped: Biological Crossroads, Certain Reasons and Maritime Network demos
(177Studio) and Stinger Wide Trial all replace letters, digits or punctuation
with "TRIAL FONT" stamps.
